# Videoaula 1 — Introdução ao Git, branches e o fluxo do HelpDesk (6 min)

**Objetivo:** entender o que é versionamento e executar o ciclo `add → commit → branch → merge`.

**Arquivos**
- [`comandos.md`](comandos.md): sequência de comandos para digitar na gravação.
- [`gitflow-helpdesk.md`](gitflow-helpdesk.md): fluxo de branches adotado no HelpDesk (diagrama).

## Roteiro de gravação
1. Problema: "e se eu quebrar o código?" (arquivos `final_v2_agora_vai.py`).
2. Git como "máquina do tempo": commit = foto do projeto.
3. Demonstração ao vivo com `comandos.md` (blocos 1 a 4).
4. Mostrar `git log --oneline --graph` com a branch criada e mesclada.
5. Apresentar o fluxo do HelpDesk (`main`, `develop`, `feature/*`).
